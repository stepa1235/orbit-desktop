# Orbit Desktop для Windows 11

Соберите приложение по инструкции ниже, запустите **Orbit Desktop.exe** и нажмите **Win+D**, чтобы перейти к рабочему столу. Нужна Windows 11 x64. Приложение автономное, отдельная установка .NET и права администратора не нужны. Первый запуск может занять чуть больше времени из-за распаковки встроенных библиотек.

Orbit использует личный и общий рабочие столы Windows и показывает их реальные файлы, папки и ярлыки. Сцена закреплена над рабочим столом Проводника как окно, владельцем которого является сам рабочий стол. Обычные окна и панель задач находятся над сценой. Исходные файлы, ярлыки, обои и расположение иконок Проводника сохраняются.

- **Один клик** открывает приложение или файл через Windows. **Правая кнопка** открывает меню с закреплением, копированием файла и пути, свойствами и показом в Проводнике. Переименование, перемещение и удаление можно выполнить в Проводнике.
- **Перетащите объект** на другое место. Orbit предложит ближайшую свободную точку на орбите. Закреплённые объекты можно открепить через меню. **Перетащите пустую область** для смещения камеры и **прокрутите колесо** для изменения масштаба.
- Кнопка **Поиск** ищет по имени и типу. **Enter** подсвечивает выбранный объект на орбите, **Ctrl+Enter** открывает его. Внизу сцены можно выделить категорию. Камеру можно сбросить в настройках и в контекстном меню фона.
- В **⋯** доступны вращение, подписи, группировка, звёзды, количество орбит, свечение, частота кадров и три вида ядра. Для больших каталогов Orbit может добавить орбиты автоматически. Новые объекты подхватываются без ручного обновления.
- Ярлык приложения можно назначить центром из настроек или выбрав **«Поместить в центр»** в его контекстном меню. Клик по центру открывает это приложение. Оно временно исчезает с орбиты и возвращается туда при выборе **«Обычное ядро»**.
- Автозапуск включается в настройках. Для него расположение EXE должно оставаться прежним.

Выберите **«Вернуть стол Windows»** в настройках или **«Показать или скрыть Orbit»** в меню значка рядом с часами, чтобы снять слой. Для полного отключения снимите галочку автозапуска и выберите **«Выход и возврат рабочего стола»** в меню значка. После выхода программу можно удалить как обычную папку. Настройки и позиции лежат в %LOCALAPPDATA%\Orbit Desktop\settings.json. Эту папку можно удалить, если вы хотите сбросить состояние.

У Spotify, Obsidian, Blender, Unity Hub, Steam, Roblox, Tor Browser и VALORANT нарисованы отдельные векторные знаки. Остальные приложения используют монохромные системные эмблемы в общей оболочке объекта. У папок и файлов собственные геометрические формы. Системные виртуальные элементы, например «Корзина», в каталог не входят.

Для каждого монитора строится отдельная сцена с общими объектами и настройками. По умолчанию орбиты плавно замедляются после 1,8 секунды без движения мыши. Когда сцена останавливается, Orbit прекращает запросы кадров. Снимите галочку **«Экономия GPU»**, чтобы орбиты вращались постоянно. Наведение, движение камеры и перетаскивание обновляются синхронно с композицией Windows, до 60 кадров/с по умолчанию. Ранее выбранный лимит можно поменять в настройках. Если монитор почти полностью перекрывает активное окно, слой приостанавливает анимацию.

На одном экране с запущенным Wallpaper Engine подтверждено, что окно новой сборки видно, им владеет рабочий стол Проводника и панель задач остаётся над ним. Закрепление меняет порядок окон на уровне Windows. Исчезновение краткой вспышки при Win+D и при нажатии «Показать рабочий стол» в этой сборке ещё не подтверждено. Другие конфигурации оболочки, второй экран, перезапуск Проводника, автозапуск после входа, игровой FPS и длительное потребление памяти не проверялись.

Снимок [menu.png](menu.png) показывает оформление контекстного меню.

Исходники находятся в **Source**. Из каталога приложения сборка с помощью .NET 9 SDK для Windows выполняется командой:

    dotnet publish .\Source\OrbitDesktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o .\publish
